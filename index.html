Backup esterno
I backup locali sono nello stesso archivio dell'iPad: esporta periodicamente un JSON su iCloud Drive per proteggerti dalla perdita dei dati del browser.

        

        
Dopo l'esportazione verifica che il file sia presente in File → iCloud Drive. L'app non può salvarlo automaticamente senza il tuo intervento.

        
Copie locali automatiche
Una copia giornaliera fino a 30 giorni; fino a 30 copie protette prima delle modifiche importanti. Non sono backup esterni.
